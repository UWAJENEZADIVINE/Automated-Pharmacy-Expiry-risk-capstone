# Automated Pharmacy Supply Chain and Expiry Risk Monitoring

## Project Description

This project focuses on improving the pharmacy supply chain process through batch intake, automated expiry risk monitoring, and prescription dispensing.

It describes how medicine shipments are received and inspected, how medicine batches are registered and monitored for expiry risks, and how valid medicines are dispensed to patients.

The main objective is to improve inventory tracking, reduce medicine wastage caused by expired products, and support safe and efficient medicine dispensing.

## Main Actors

1. **Supplier / Distributor:** Prepares and delivers medicine shipments to the pharmacy.
2. **Pharmacy Inventory Manager:** Receives shipments, checks delivered stock, registers medicine batches, and monitors expiry risks.
3. **Dispensing Pharmacist:** Verifies prescriptions, checks medicine availability and validity, dispenses medicines, and updates stock quantities.

## Key Activities

- Receiving and inspecting medicine shipments.
- Registering medicine batches and recording stock quantities and expiry dates.
- Monitoring medicine batches for expiry risks.
- Generating automated alerts for batches approaching their expiry dates.
- Identifying and quarantining expired medicines.
- Verifying prescriptions and checking available stock.
- Dispensing valid medicines and updating remaining stock quantities.

## Expected Outcome

The process aims to improve inventory accuracy, reduce losses caused by expired medicines, support timely identification of expiry risks, and ensure that patients receive safe and valid medicines.
